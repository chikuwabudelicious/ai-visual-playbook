# video-format-recipes — 動画の型を選び、データで量産する

手元に素材が無くても、このスキルを読めば「どの型で・何秒で・どんな順で見せるか」が決まり、
台本・カット表・生成AIへの指示・組み立て・検査まで一本道で進められるようにしたもの。
中身は、ある中小企業が1年かけて社内で作った動画の型と、そのとき踏んだ罠を一般化したもの。

| 読むもの | いつ |
|---|---|
| `references/formats.md` | 型を選ぶとき。35型の用途・比率・尺・拍の表（秒ごとの見せ方）・素材・量産の単位 |
| `references/prompts.md` | 依頼文・生成AIへの指示を書くとき。ブリーフ、型ごとの依頼文、映像・画像・BGM・声・台本の指示の型 |
| `references/pitfalls.md` | 作る前と、おかしいと思ったとき。症状→原因→対処の一覧 |
| `templates/` | すぐ1本作りたいとき。JSON を書き換えるだけで書き出せる見本3型（数字1つ・数えて分かる・くらべて見る） |

## 進め方（7手）

1. **ブリーフを7項目で固める**（`prompts.md` §0）。目的／視聴者／置き場所／比率と尺／音／原本（数字・文言の出どころ）／禁止事項。
   埋まらない項目は型の既定値で進め、最後に「要確認」としてまとめて返す
2. **型を選ぶ**。下の早見表で目的と置き場所から候補を2〜3に絞り、`formats.md` の節で尺と素材を確かめる。
   迷ったら推奨案を1つ添えて1問だけ聞く
3. **拍の表を写して台本とカット表にする**。型の表の「区間・秒・中身・見せ方」をそのまま行にし、中身の欄だけ埋める。
   文言・数字は JSON（1本＝1ファイル）に書き、HTML に直書きしない
4. **素材を作る**（下の「素材の作り方」）。足りない絵・映像・音だけを生成する。文字・数字・グラフは生成せずコードで描く
5. **組み立てる**（HTML→MP4）。時刻は音から機械で決める：ナレーションありなら1文ずつ合成して尺を実測、無音なら BGM の拍に置く
6. **静止画で確かめてから書き出し、機械QA＋目視**（下の「機械QA」）
7. **2本目以降はデータを足すだけ**にする。テンプレートを直したら全話を書き出し直す

## 原則（ここを外すと作り直しになる）

- **文字・数字・グラフはコードで描く。** 生成映像・生成画像は文字を正しく描けない。テロップ・数字・社名は HTML の層に重ねる
- **数字は原本にあるものだけ。** 棒の長さ・カウントアップの到達値・アイコンの数も「数字」。原本に比率が無ければ等量で描く。無い数字は「（要確認）」にして返す
- **時刻は測った値から。** 手で秒を打たない。声は1文ずつ合成して尺を実測、BGM は拍を解析して「拍番号」で出来事を置く
- **音なしで再生されても伝わるように。** SNS のフィードは無音で自動再生される。最初の3秒で問いか結論を読ませ、字幕は焼き込む。
  縦 1080×1920 では上220px・下420px・右140px に読ませる文字を置かない（アプリの UI に隠れる）
- **1本目は「テンプレート＋データ1件」で作り、静止画で見せてから書き出す。** 同じ不具合が N 本に入るのを防ぐ
- **成否は出力ファイルで判定する。** 書き出し前に前回の mp4 を消す。ログの読み込み失敗は不合格
- **生成した映像・人物を、実在の施設・人物・記録映像として紹介しない。** 「AI生成」等の注記の要否は、公開先の規約と各地の法令に従う
- **公開・投稿・送付は人が判断する。** AI は書き出しと検査まで

## 素材の作り方（モデル名は 2026年11月時点で使えた名前。名前・料金・仕様は変わるので、使う前に各社の一次資料で確かめる）

| 素材 | 第一候補 | 使い方の要点 | 指示の型 |
|---|---|---|---|
| 場面の静止画・挿絵・部品 | OpenAI の gpt-image 系（2026-11 時点で gpt-image-2 とその派生版） | 画風固定文を一字一句そろえる。部品は「1枚に12個」描かせて切り分けると絵柄がそろう | `prompts.md` §2-3・§2-4 |
| 映像の動き | Google の Veo 3.1 系（Vertex AI・Gemini API。後継・別名に移ることがある）。代わりに Sora 2・Seedance・Kling など | 静止画を始点にした 4〜8 秒。1ショット1動作。生成物の音は捨て、文字は重ねない | `prompts.md` §2-1 |
| BGM | Google の Lyria 3 系などの音楽生成モデル、または利用条件を確かめた手持ちの曲 | テンポ・楽器・「どこを切っても同じ勢い」を指定。生成後に拍を実測してから使う | `prompts.md` §2-5 |
| ナレーション | Gemini の TTS（2026-11 時点で gemini-3.8-flash-tts。声は Charon などの名前で選ぶ）、OpenAI の TTS など | 1行1文で台本を書き、1文ずつ合成して尺を実測。必ず書き起こして原稿と照合 | `prompts.md` §2-6 |
| 書き起こし（照合・字幕） | faster-whisper（ローカル）、Gemini の書き起こし | 一致度だけで合格にしない。頭とお尻の数語を原稿と突き合わせる | `pitfalls.md` 声の節 |
| 映像の見直し | 動画を読める多モーダルモデル（Gemini など） | 完成動画と台本を渡し、食い違いを時刻つきで挙げさせる。合否には使わず、人がコマで確かめる補助 | `prompts.md` §3 |

費用の目安（2026-10時点・各社の公開価格から。変わる）：Veo 3.1 fast 720p で 1秒約0.10 USD（6秒1本で約0.6 USD）、std は約4倍。
5本を超える生成は、本数と見積もりを人に見せてから回す。

## 組み立て（HTML→MP4）

| 道具 | 向くもの |
|---|---|
| **HyperFrames**（HTML＋CSS＋GSAP を動画にする OSS。`npx hyperframes`） | テロップ・図解・数字・型もの全般。`render --variables-file x.json` で1話ずつ差し替えられる |
| **ffmpeg**（＋Pillow で文字を PNG に） | 既存の映像・音声を切る・つなぐ・重ねる型（F22・F24・F25・F26）。ブラウザが要らず軽い |
| Chrome＋ffmpeg（自前でコマを撮る） | HyperFrames が使えない環境。`templates/capture.py` に最小の例 |
| Remotion（React） | React の資産があるとき。企業利用はライセンスを確認 |

量産の形（どの型も同じ）：

```
<シリーズ>/
  index.html          テンプレート1本（data-composition-variables で変数を宣言）
  episodes/ep01.json  1本＝1ファイル（文言・数字・図の種類）
  assets/             BGM と拍（beats.js）、ナレーションなら1文ずつの wav と timing.json
  make.py             事前検査 → 書き出し → 事後検査 → タイル画像 → out/ に納品名で
```

- レイアウトが変わるならテンプレートを増やし、文言だけならJSONを増やす
- 要素の数（吹き出しのターン数など）が話ごとに変わる型は、変数ではなくスクリプトが JSON と実測の尺から HTML を書き出す
- 長いものは1単位（1問・1章）ずつ書き出して ffmpeg で連結する（落ちたときのやり直しが小さい）
- 長尺のループ（待機画面など）は短いループだけ HTML で書き出し、ffmpeg でつなぐ

## 機械QA（書き出したら毎回）

```bash
# 尺・解像度・音声の有無（映像ストリーム単体の尺も見る）
ffprobe -v error -show_entries stream=codec_type,width,height,duration:format=duration -of json out.mp4
# ラウドネス（目安：配信 −16〜−14 LUFS、トゥルーピーク −1.5 dBFS 以下。AAC にした後の値で見る）
ffmpeg -i out.mp4 -af loudnorm=print_format=summary -f null - 2>&1 | tail -12
# 黒コマ・止まったコマ（終了コードも見る。失敗して空の結果を「検出なし」と読まない）
ffmpeg -i out.mp4 -vf "blackdetect=d=0.1:pix_th=0.05,freezedetect=n=0.003:d=1.5" -an -f null - 2>&1 | grep -E "black_|freeze_"
# 1秒おきのコマを並べた一覧画像（コマの間に余白を入れる。縦動画なら tile=6x4 など）
ffmpeg -i out.mp4 -vf "fps=1,scale=360:-2,pad=iw+12:ih+12:6:6:white,tile=6x4" -frames:v 1 tiles.png
```

- 一覧画像は AI に読ませて目視する（文字のはみ出し・重なり・豆腐・ちらつき・読む前に消える文字）。0.5秒以下しか出ない要素は一覧で写らないので、その時刻を個別に撮る
- 書体に無い字（豆腐）と禁止語は、書き出す前に JSON の全文字で検査する（fontTools の cmap）
- 画面に焼き込まれた文字（元動画のテロップ・図の中の数字）は字幕ファイルの検査では拾えない。コマを見る

## templates/ について

`templates/` に、ロゴ・BGM・書体ファイルを含まない最小の見本を3型入れた（数字1つ＝F05、数えて分かる＝F17、くらべて見る＝F04 の静かな版）。
書体は Google Fonts の Noto Sans JP、GSAP は cdnjs から版を固定して読む（書き出しにネット接続が要る）。BGM は任意で、
書き出し後に ffmpeg で重ねる。手順は `templates/README.md`。他の型は `formats.md` の拍の表と `prompts.md` の依頼文から AI に組ませる。
